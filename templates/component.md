# Component content template

Publish as `kind: component`, with a safe descriptive slug, contributing `source_paths`, and `review_status: draft`.

**Summary:** the component's evidenced responsibility and declared result.

- **Boundary and entry points:** the files and interfaces establishing this component.
- **Responsibilities:** major operations and where their implementation lives.
- **Relationships:** verified inputs, dependencies, outputs, and consumers.
- **Configuration and decisions:** the sources that select behavior.
- **Failure boundaries and unknowns:** relevant handling paths and unresolved external context.

Use verified wiki targets for navigation. Explain shared responsibilities once here and link to concise file notes. Do not infer a module boundary solely from a folder name.
